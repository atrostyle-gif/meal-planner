# localStorage → Supabase 移行

## いつ表示されるか

Supabase モードで家庭を作成または参加したあと、  
この端末にデータがあり、まだその家庭へ移行していない場合に確認ダイアログが出ます。

## 選択肢

- **移行する** … レシピ・献立・買い物リスト・冷蔵庫・常備品を upsert
- **今は移行しない** … クラウド側のデータを優先して利用

## 安全策

- 元の localStorage は自動削除しない
- サンプルは名前 / ID で重複投入を抑制
- 移行結果を件数表示
- マーカー `meal-planner:cloudMigration` で再移行を抑制
- 一部失敗しても成功分は残る（エラーメッセージに内訳）

## 手動再実行

設定画面の「この端末データを家族へ移行」から再実行できます。
