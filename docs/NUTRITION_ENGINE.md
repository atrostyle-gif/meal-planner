# 栄養エンジン

家庭の献立作成を補助するための栄養計算・最適化の説明です。**医療診断・治療目的ではありません。**

## 計算方法

1. 材料名を食材マスターへ紐付け（canonical / aliases）
2. 数量を g 相当へ換算
3. 100g あたり栄養 × 使用量で合算
4. 人数で割って 1人分を算出

## 計算できない材料

- 適量・少々
- マスター未登録
- 単位換算不能

→ 0 にはせず、未計算として件数・一覧に残します。

## 値の種類

- 材料から自動計算
- 手動入力
- 推定値
- 未計算

## 単位換算

対応: g, kg, ml, L, 個, 本, 枚, 玉, 束, 袋, パック, 缶, 大さじ, 小さじ

## 献立エンジン v3

1. ハード制約（アレルギー・食事制限・時間）
2. 候補スコアリング
3. 1日組み合わせ評価
4. 提案プレビュー → 採用で確定

## 献立エンジン v4

v3 に加え、曜日の生活スケジュール・担当者適性・週間食材活用を評価します。詳細は `docs/MEAL_PLANNER_V4.md`。
