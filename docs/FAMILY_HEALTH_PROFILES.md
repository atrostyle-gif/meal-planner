# 家族プロフィール（統合）

`/settings/family-profiles` で、家族一人ひとりと家庭全体の設定をまとめて管理します。

## メンバー（一人ごと）

- 基本情報（名前・年齢・性別・食べる量）
- 健康・食事（アレルギー・苦手/好き・食事制限・健康チェック）
- 栄養目標（標準自動計算 / 手動）
- 食事の好み（AI学習）
- 調理担当曜日
- AIメモ

## 家庭全体

- 通常の食事人数
- 献立方針
- 健康方針（糖尿病・体重管理サポート）
- よく買い物する店（専用画面へ）

## 方針

- 性別・年齢は任意
- 目標値は参考情報（医療判断には使いません）
- アレルギーは原材料表示も必ず確認
- 旧データは読み込み時に自動移行

## 旧URL

- `/settings/health-nutrition` → `?section=health`（家庭全体へ）
- `/settings/lifestyle-setup` → `?section=lifestyle`
- `/settings/cooking-members` → メンバー編集へリダイレクト
