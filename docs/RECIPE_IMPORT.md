# レシピ取り込み

レシピ登録画面では手入力、URL、写真を選べます。取り込み後は必ず確認画面を経由し、ユーザーが保存を実行するまでレシピは保存されません。

## URL

ハイブリッド方式です。詳細は `docs/RECIPE_URL_IMPORT.md` を参照してください。

1. 十分な JSON-LD Recipe があればそれを採用（AI なし）
2. なければ HTML を前処理して AI で構造化
3. HTML ルールは AI 入力候補と、API キー未設定時の限定フォールバック

## 写真

- 最大5枚、JPEG / PNG / WebP、各元画像10MBまで
- 完成料理だけの写真は、材料・手順を推測して登録しません

## 共通

出典、取り込み方法、献立向け分類（mealAffinity）、注意事項はレシピと一緒に保持されます。localStorage / Supabase 同期の既存経路は変更しません。
