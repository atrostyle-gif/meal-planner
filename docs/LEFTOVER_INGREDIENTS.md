# 余っている食材

`/meals` の「今週の献立を作る」直前に、冷蔵庫などに残っている食材をチップで入力します。

## 方針

- 本格的な在庫・賞味期限管理は行わない
- 入力された食材はすべて「今週使い切りたい食材」として同じルールで評価する（優先度なし）
- 週間献立（`weekStart`）に紐付けて保存し、次週へ自動持ち越ししない
- 前回入力は候補表示のみ（明示選択が必要）

## 反映先

- 週間献立の自動編成スコア（余り食材活用）
- 生成後の使用／未使用サマリー
- 買い物リスト（数量ありは差し引き、数量なしは確認メモ）
- 今日画面 tip（今日の献立で実際に使う場合のみ）
